Данный модуль парсит файлы реестров счетов по диспансеризации в формате .xml выгруженные из ЦМИС
Далее в зависимости от этапа он пошагово, сравнивает услуги в каждом случае с теми услугами которые
заранее занесены в файл _sample.php.
В итоге он выдает те записи с персональными данными, а так же список услуг который не соответсвует шаблону
Файл _sample.php отличается в зависимости от вида диспансеризации и заполнаяется на основе шаблона с сайта omspk.ru
Файл представляет с собой массив деленый на два ключа 1-мужчины, 2-женщины для 1 диспансеризации и проф осмотров
и просто массив для других видов диспансеризации
