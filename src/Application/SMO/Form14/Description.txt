Данный модуль получает на вход данные из сформированных счетов на сайте 192.168.10.28 - ФОНД
Считывает xls файлы и формирует на их основе счета для СМО по 14 форме
Каждый поданный на вход счет в формате: "назвыание-номер счета в ФОНД.xlsx"
Пример файла: 1й этап дисп-25.xlsx
Формирует файл по типу: [Счет ТФОМС №25] 1й этап дисп.xlsx
